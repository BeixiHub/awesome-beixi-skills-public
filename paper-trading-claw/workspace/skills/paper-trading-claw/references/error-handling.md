# 错误处理话术

这份文档只定义对用户的标准说法，不要把内部字段、文件路径或底层报错细节直接甩给用户。

## 注册相关

### 缺手机号

```text
把你的手机号发给我，我来帮你直接开通模拟盘。
```

### 手机号不合法

```text
这个手机号看起来不对。请发我一个有效的 11 位大陆手机号，我再帮你开通模拟盘。
```

### 注册失败

```text
这次开通没有成功，你稍后再试一次，我也可以继续帮你重试。
```

### 已提交但未确认可交易

```text
开通请求已经提交，但现在还没确认能不能直接交易。你可以稍后让我再查一次状态。
```

## 状态和查询

### 未绑定

```text
你现在还没有开通模拟盘，把手机号发给我，我来帮你开通。
```

### 查询成功但没有数据

```text
查询成功，但当前还没有相关数据。
```

### 状态异常

```text
我暂时还没确认到这个模拟盘当前是否可用。你可以稍后再查一次。
```

## 下单相关

### 缺股票

```text
告诉我要操作哪只股票就行，给我股票名称或者 6 位代码都可以。
```

### 缺数量

```text
告诉我要买卖多少股。
```

### 缺价格

```text
如果你不知道价格，我可以优先按当前盘口价格帮你处理；只有拿不到盘口行情时，我才会再让你补价格。
```

### 缺 innerCode

```text
这只股票当前还缺少交易映射信息，我暂时没法直接下单。你可以先提供 innerCode，或者先查一次相关持仓/委托。
```

### 下单失败

```text
这笔委托没有提交成功。原因是：{message}
```

### 下单结果不明确

```text
委托接口已经返回了，但现在还没法明确确认这笔单子是否真正挂出。我可以继续帮你查今日委托。
```

## 撤单相关

### 委托已经不是待成交

```text
这笔委托当前已经不是待成交状态，不能再按普通撤单处理。我可以继续帮你查看它现在的状态。
```

### 撤单结果未确认

```text
我已经发起撤单，但现在还没确认撤单成功。我可以继续帮你查这笔委托的状态。
```

### 撤单成功

```text
这笔委托已经确认撤销成功。
```
