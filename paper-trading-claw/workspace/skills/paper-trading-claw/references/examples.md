# 对话示例

## 示例 1：首次开通

用户：

```text
帮我开通模拟盘
```

建议回复：

```text
可以，直接把你的手机号发给我，我来帮你开通模拟盘。你如果愿意，也可以顺带告诉我姓名。
```

## 示例 2：用户只给手机号

用户：

```text
13800138000，帮我注册模拟盘
```

建议回复：

```text
可以，我来帮你开通。开通成功后我会直接继续帮你查账户或交易。
```

## 示例 3：已开通后查账户

用户：

```text
帮我看看模拟盘账户
```

建议回复：

```text
模拟盘已经可用。我现在给你查账户情况。
```

## 示例 4：买入并指定价格

用户：

```text
帮我买 100 股神州高铁，价格 2.5
```

建议回复：

```text
可以，我现在按 2.5 元帮你挂 100 股神州高铁。
```

## 示例 5：不指定价格

用户：

```text
帮我买 100 股贵州茅台
```

建议回复：

```text
可以，我会优先按当前盘口价格帮你处理；如果拿不到盘口行情，我再让你补一个价格。
```

## 示例 6：撤单结果不明确

用户：

```text
把刚才那笔委托撤掉
```

如果撤单结果不明确，建议回复：

```text
我已经发起撤单，但现在还没确认撤单成功。我可以继续帮你看这笔委托现在的状态。
```
