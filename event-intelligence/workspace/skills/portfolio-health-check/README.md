# Portfolio Health Check

面向投资者的三阶段组合诊断与优化服务。

这个 skill 的目标不是直接给出买卖指令，而是帮助用户把当前持仓整理清楚，逐步完成：

1. 持仓确认与快速诊断
2. 深度诊断
3. 优化处方

整体体验上，它更像一个分阶段顾问：

- 先确认你到底持有哪些资产
- 再判断组合目前有哪些风险与结构问题
- 最后在你的约束下给出优化方向

---

## 适合什么场景

适合以下类型的问题：

- “我现在这个组合整体怎么样？”
- “我的仓位是不是太集中？”
- “如果我还想继续投，下一步应该怎么优化？”
- “我想控制风险、但又不想完全换掉现有持仓，能怎么调整？”

不适合的场景：

- 单纯要一只股票的短线买卖建议
- 要求系统替用户自动交易
- 希望在信息极度不完整的前提下直接给出结论

---

## 三个阶段

### 第一阶段：快速诊断

这一阶段的重点，是把用户当前持仓整理成一份可以确认的结构化结果。

系统通常会收集这些信息：

- 持有哪些标的
- 每个标的大致仓位、金额、股数，或至少名称
- 是否有现金，以及现金大概占多少
- 如果用户只提供了名称但没有仓位，系统会先尽量补全，再请用户确认

这一阶段面向用户的输出主要包括：

- 标的名称与代码确认表
- 每个标的的基础说明
  - 例如公司/基金的基本身份
  - 所属行业或大类方向
- 持仓确认表
  - 包括各标的占比
  - 现金占比
  - 需要用户进一步确认的项目
- 快速诊断结论
  - 组合是否偏集中
  - 资产分布是否单一
  - 有没有明显的结构性问题

简单理解：第一阶段先解决“你现在手里到底拿着什么”。

---

### 第二阶段：深度诊断

这一阶段会基于用户确认后的持仓，做更完整的组合分析。

系统会收集这些信息：

- 换仓频率
  - 日内 / 周度 / 月度 / 季度 / 长期持有
- 仓位管理风格
  - 比如偏择时、偏轮动、偏定投、偏核心卫星
- 风险承受力
  - 保守 / 稳健 / 积极 / 激进
- 投资期限
  - <1年 / 1-3年 / 3-5年 / 5年以上
- 总投资金额
  - 可选，但有助于做更完整的流动性判断

这一阶段面向用户的输出主要包括：

- 一份深度诊断报告
  - 默认优先输出 PDF 报告
  - 如果 PDF 不可用，再退回结构化文字结果
- 组合诊断摘要
  - 当前组合最突出的优点和短板
- 风险与波动相关结论
  - 例如组合整体风险水平
  - 哪些持仓可能拖累组合稳定性
- 集中度与分散度结论
  - 是否过度押注个别标的或行业
- 与基准或常见市场参考的对照
  - 帮助用户理解组合表现所处的位置
- 因子、行业、流动性等维度的补充判断
  - 用来解释“为什么会这样”

简单理解：第二阶段解决“这个组合现在好不好，问题具体出在哪儿”。

---

### 第三阶段：优化处方

这一阶段不会脱离用户现实条件，而是在用户约束下给出可执行的优化方向。

系统会收集这些信息：

- 可投资市场
  - A股 / 港股 / 美股
- 可使用工具
  - 股票 / ETF / 基金 / 期货 / 期权 / 加密资产等
- 还有多少可追加资金
  - 没有 / 还有 10-30% / 30-50% / 50%+
- 投资目标
  - 资产增值 / 现金流 / 对冲风险 / 打新底仓
- 可接受敞口
  - 可选
- 账户已开通权限
  - 可选

这一阶段面向用户的输出主要包括：

- 优化处方结果
  - 在当前约束下可以怎么改
- 建议的优先级
  - 哪些调整更适合先做
  - 哪些属于后续迭代动作
- 约束下的可行方案
  - 不会脱离“你能买什么、还能投多少、追求什么目标”
- 总结性建议
  - 这套方案希望改善什么问题
  - 更适合什么样的风险偏好和持有方式

简单理解：第三阶段解决“在你现有条件下，下一步怎么调更合理”。

---

## 用户大概会被问到什么

从用户体验看，这个 skill 会尽量避免一次性问很多问题，而是分阶段收集。

典型顺序是：

1. 先确认持仓与现金归属
2. 再补深度诊断所需的 4 个核心参数
3. 最后只在用户需要优化方案时，再收集约束

因此用户通常不会一开始就被要求把所有信息一次性说完。

---

## 用户最终能拿到什么

完整体验下，用户会逐步拿到三类结果：

1. 一份持仓确认结果
2. 一份组合深度诊断结果
   - 通常优先是 PDF
   - 或结构化中文说明
3. 一份优化处方
   - 面向下一步调整方向
   - 强调约束下的可行性，而不是理想化建议

---

## 这套服务的边界

为了让输出更稳健，这个 skill 默认遵守几条边界：

- 不编造数据
- 不直接给出具体买卖指令
- 会优先区分“已确认信息”和“待确认信息”
- 如果用户信息不完整，会先补关键信息，再进入下一阶段

所以它更像一个“组合诊断与优化助手”，而不是“自动荐股工具”。

---

## 一句话总结

这套 Portfolio Health Check skill 会把一次组合分析拆成三步：

- 第一步看清持仓
- 第二步看懂风险与结构
- 第三步在用户约束下给出优化方向

它最核心的价值，不是替用户拍板，而是帮助用户把组合状态、问题来源和可行动作讲清楚。
