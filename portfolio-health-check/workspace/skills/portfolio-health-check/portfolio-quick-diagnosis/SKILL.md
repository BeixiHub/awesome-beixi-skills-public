# 投资组合快速诊断

## 目标

把用户持仓整理成可确认的结构化结果，并输出简洁的快速诊断。

## 你负责

- 识别标的名称和代码
- 整理仓位与现金归属
- 生成持仓确认表
- 在确认后输出快速诊断

## 核心规则

- 全程中文。
- 不给买卖指令。
- 先做标的识别和整理，再提问。
- 只问完成当前阶段所必需的最少信息。
- 最多补问 3 轮。
- 本技能只负责第 1 阶段，不处理 Phase 2 / 3。

## 标的识别

- 阶段一开始后，必须至少调用一次 QVeris `identify`。
- 优先补齐：名称 / 代码、公司简介、行业简介。
- 名称有歧义时标记为待确认，并列候选代码。
- QVeris 找不到时，再用公开信息补基础背景。

## 仓位补全逻辑

用户提供持仓时可能出现以下情况，按优先级处理：

1. **给了占比或金额** → 直接使用，归一化为百分比。
2. **给了股数** → 通过 web search 查询该股票最新股价，计算市值（股数 × 股价），再归一化为占比。在确认表中标注"市值为网络查询估算"。
3. **只给了股票名，没有任何仓位信息** → 通过 web search 查询每只股票的最新总市值，按市值比例计算占比，生成确认表让用户确认。在确认表中标注"占比为按市值估算，请核实"。
4. **比例合计不足 100%** → 不能默认剩余是现金，必须问清归属。

**web search 查询要求**：
- 搜索关键词示例：`贵州茅台 最新股价` 或 `600519 市值`
- 取最近交易日的收盘价或最新市值
- 如果搜不到可靠数据，标记为"待确认"并向用户询问

## 信息收集顺序

1. 识别全部标的（名称 + 代码）。
2. 整理每个标的的输入形式：比例、金额、股数或仅名称。
3. 如果缺少仓位信息，web search 查询市值并估算占比。
4. 识别现金线索和剩余资金归属。
5. 输出确认表（含数据来源标注）。
6. 用户确认后，再生成分析结果。

## 必问范围

只在以下情况询问用户：

- 标的名称或代码无法确认（有歧义）
- 比例未满 100%，剩余部分归属不明
- web search 也查不到可靠市值数据

**不再需要询问的情况**：
- 用户只给了股票名没给仓位 → 自动 web search 估算，出表确认
- 用户只给了股数 → 自动 web search 查股价计算市值，出表确认

## 输出顺序

1. 名称/代码互查表
2. 公司与行业简介
3. 持仓确认表
4. 快速诊断结果

确认提示保持简短，例如：请确认下表；如有不准，请直接改名称、代码、仓位或现金占比。

## 边界

- 对不确定信息写"待确认"或"无法确认"。
- ETF 与个股重叠只做保守判断。
- 完成快速诊断后，不继续展开分析，只询问是否进入深度诊断，并列出所需参数。
