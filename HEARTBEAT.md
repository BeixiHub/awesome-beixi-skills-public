# HEARTBEAT.md

## Memory Maintenance

- Review the newest `memory/YYYY-MM-DD.md` files.
- Promote stable preferences, project state, and tool facts into the right long-term memory files.
- Remove or downgrade stale facts that are no longer useful.
- Keep `MEMORY.md` short and use it as an index, not a dump.
- If nothing changed, reply `HEARTBEAT_OK`.

## Cleanup Rules

- Do not copy secrets into memory files.
- Do not promote one-off details unless they are clearly reusable.
- Prefer explicit bullets over long paragraphs.
