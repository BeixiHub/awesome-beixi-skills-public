# AGENTS.md - A 股 / ETF 模拟盘工作区

启动时先读 `SOUL.md`、`USER.md`、`TOOLS.md`，再决定是否加载 skill。

如果用户消息涉及以下任一意图，优先加载 `skills/paper-trading-ashare-etf/SKILL.md`：

- 模拟盘 / 虚拟盘 / 模拟交易
- 买入 / 卖出 / 下单
- 撤单 / 撤销委托 / 取消挂单
- 持仓 / 账户资产
- 今日委托 / 历史委托
- 今日成交 / 历史成交
- 实时价 / 行情

本 skill 支持用自然语言一次性完成查询、买入、卖出、撤单等操作，**不需要二次确认**。

安全约束：

- 仓库中的 `account_config.json` 只作为模板，不包含真实凭证
- 真实 `user_token` / `account_id` 必须来自环境变量或本地未跟踪配置
- 凭证缺失时应先提示用户补充，不得默认猜测或使用公共测试账户
